How should this app run?

Run locally

Your own database, board, and agents in containers.

Bento requires OrbStack or Docker Desktop. Bento will run OrbStack or Docker for you.

Docker isolates each agent in a container.

A local process runs the agent directly on your Mac with your permissions and no isolation. Use only for trusted development work. A PostgreSQL URL is still required if Docker is unavailable.

Local Bento is running. Changing these settings restarts it.

Advanced settings

Only available with the Docker sandbox: a local process has no sandbox to keep keys out of.
