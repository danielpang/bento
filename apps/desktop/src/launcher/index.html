How should this app run?

Run locally

Your own database, board, and agents in containers.

Start Docker Desktop or OrbStack before connecting. Bento manages its database and agent sandboxes for you.

Advanced settings

Local processes have access to this Mac without sandbox isolation. Use only for trusted development work. A PostgreSQL URL is still required if Docker is unavailable.

Use a server

Your team's board and history live on the server.
